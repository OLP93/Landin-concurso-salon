# Concurso del Salón

Landing de concurso para un salón de uñas: capta contactos de forma transparente con doble validación y sorteo auditable.

## Qué incluye
- Inscripción con validación y confirmación por correo
- Cierre automático de inscripciones en la fecha límite
- Consentimientos separados (bases y comunicaciones)
- Panel de administración: participantes, exportación CSV y sorteo aleatorio con suplentes
- Bases legales, privacidad y aviso de cookies

## Tecnologías
React · TypeScript · Tailwind CSS · shadcn/ui · react-hook-form · zod

## Estado
Los datos se guardan en el navegador (sin backend) y el envío de correos está simulado.
